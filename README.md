# Detour Flights

A simple React + TypeScript flight-search frontend for [gflight.q1z.dev](https://gflight.q1z.dev). UI components use Radix Themes. The browser calls the public API directly; no credentials or backend are needed.

## Development

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

The production build is a static site in `dist/`.
